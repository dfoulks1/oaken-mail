Oaken Mail home

Two demos, two products

Oaken Core and the OakenMail web client are different things. Core is the engine that ships today; the web client is a preview of a separate product still being built. Pick one.

OakenCore
Shipping · 0.1.x

The pipeline, CLI and MCP server — the product that lets an AI work with your mail, locally. This demo is Core's own browser console: the read-only status page, the jobs and pipeline view, and the config.toml editor the daemon serves on loopback.

Status · Jobs · Config · Getting started
OakenMail WebUI
Preview · not shipped

A separate client: the browser mail app (inbox, reader, compose, search, settings). It is a mockup — the data is dummy fixtures and several screens are still to come. It builds on Core's API; it is not part of Core.

Inbox · Compose · Search · Settings

Why two? Core stays headless (it serves only the read-only console above); each UI is its own product built on Core's HTTP API. See the architecture decisions for the split.
