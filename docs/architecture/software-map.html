Conventions

  • Calls go down. A component may call its own layer or a lower one, never a higher one, and the call graph has no cycles.
  • Events go up. Lower layers reach higher ones only through events or a handler the higher layer registered.
  • Plugins meet core at a contract. Core never imports provider code, and a plugin never touches the databases.
  • Mail is data. Anything that handles message text is marked untrusted, and its text reaches a model only as UntrustedText.
  • Mutations are gated in code. The operation registry's confirm gate, not a prompt, decides whether mail may change. Sending is never exposed over MCP.
  • index.db is disposable. Everything in it can be rebuilt from raw.db.
