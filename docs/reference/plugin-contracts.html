Plugin contracts

The signatures, data types and capabilities of the five plugin kinds, generated from the code.

This page is generated from src/oaken/plugins/contracts.py and src/oaken/plugins/base.py, so it always matches the code. For a walkthrough, see Writing a plugin.

The plugin API version is 1. A plugin whose api_version differs is rejected at load.

Protocols

A plugin satisfies a contract by having these members.

Plugin

Lifecycle, shared by every kind. All three are optional for a plugin to define.

async def start(self, ctx: PluginContext) -> None

Acquire resources. Raising marks the plugin unhealthy; core carries on.

async def stop(self) -> None

Release resources. Called once at shutdown.

async def health(self) -> Health

A cheap liveness check, polled periodically by the host.

Provider

A mail source. Capabilities: auth, sync.pull, flags.write, send.

async def authenticate(self, ctx: PluginContext) -> None

Make sure the plugin can talk to the service (capability auth).

def pull(self, cursor: str | None) -> AsyncIterator[PullBatch]

Yield batches of changes since cursor (None: from the start). Capability sync.pull. Re-pulling from the last cursor returns nothing new.

async def set_flags(self, provider_ids: Sequence[str], add: Collection[str], remove: Collection[str]) -> None

Write flags back to the server (capability flags.write).

async def send(self, raw_bytes: bytes) -> str

Send a message and return its provider id. Declared for the future; unimplemented in v1, and the host never routes sending to a plugin (capability send).

Embedder

Turns text into vectors.

Attributes:

  • model_id: str
  • dimensions: int
  • max_input_tokens: int
async def embed(self, texts: Sequence[str]) -> list[list[float]]

One vector of dimensions floats per text, in order.

LLMBackend

Runs a language model.

Attributes:

  • model_id: str
  • context_window: int
async def generate(self, request: LLMRequest) -> LLMResponse

Answer request. With a json_schema, data carries the parsed result.

Enricher

Derives something from one message. version is part of the cache key: bump it when the output could change.

Attributes:

  • version: str
  • needs_llm: bool
  • output_schema: dict[str, Any]
async def enrich(self, msg: EnrichInput) -> EnrichOutput

Derive this enricher's result for msg.

VectorStore

Stores vectors and finds the nearest ones.

async def upsert(self, items: Sequence[VectorItem]) -> None

Insert or replace by (message_id, chunk_id). Raises if an item's model or dimensions differ from what the store already holds, leaving the store unchanged.

async def delete(self, message_ids: Sequence[str]) -> None

Remove every vector of these messages.

async def query(self, vector: Sequence[float], k: int, filters: dict[str, str] | None=None) -> list[Hit]

The k nearest, best first. filters may name account_id and model_id; a store that sits beside the index may take more (thread_key, after, before, sender) and must refuse a filter it does not know rather than ignore it. Raises if vector does not match the stored dimensions.

async def stats(self) -> VectorStats

How many vectors, and which model and dimensions they use.

Base classes

Optional. They supply defaults so a plugin overrides only what it does.

BaseProvider

Override pull at least. Add authenticate and set_flags as the service allows. Capabilities come from what you override (pull is sync.pull, set_flags is flags.write). To state them yourself, set capabilities = frozenset({...}); the host rejects a capability whose method you did not write.

Set:

  • kind: ClassVar[PluginKind] = 'provider'

Override:

  • async def authenticate(self, ctx: PluginContext) -> None
  • def pull(self, cursor: str | None) -> AsyncIterator[PullBatch]
  • async def set_flags(self, provider_ids: Sequence[str], add: Collection[str], remove: Collection[str]) -> None
  • async def send(self, raw_bytes: bytes) -> str

BaseEmbedder

Set:

  • kind: ClassVar[PluginKind] = 'embedder'
  • model_id: str = ''
  • dimensions: int = 0
  • max_input_tokens: int = 8192

Override:

  • async def embed(self, texts: Sequence[str]) -> list[list[float]]

BaseLLMBackend

Set:

  • kind: ClassVar[PluginKind] = 'llm_backend'
  • model_id: str = ''
  • context_window: int = 0

Override:

  • async def generate(self, request: LLMRequest) -> LLMResponse

BaseEnricher

Set version and, ideally, output_model (a pydantic model): the host then checks the result against it and publishes its JSON schema. Override enrich.

Set:

  • kind: ClassVar[PluginKind] = 'enricher'
  • version: ClassVar[str] = '1'
  • needs_llm: bool = False
  • output_model: ClassVar[type[BaseModel] | None] = None

Override:

  • async def enrich(self, msg: EnrichInput) -> EnrichOutput

The @enricher decorator

def enricher(name: str, *, version: str='1', needs_llm: bool=False, output: type[BaseModel] | None=None) -> Callable[[Callable[[EnrichInput], Awaitable[object]]], type[BaseEnricher]]

Turn one async function into an enricher class, ready to register as an entry point: class Result(BaseModel): words: int @enricher("word-count", output=Result) async def word_count(msg: EnrichInput) -> Result: return Result(words=len(msg.body.unwrap().split())) The function may return the model, a dict or an EnrichOutput; the host coerces it.
